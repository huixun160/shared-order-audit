# 阴性对照：Shin 2018 词语生成（WG），2026-10-06

脚本：`scripts/26_shin_wg_control.py`；结果：`results/shin_wg_control/summary.csv`。
被试、设备、session 和预处理都与 n-back 阳性数据相同（因果滤波，窗口结束于 2 s 指导语之前，4 s 窗口）。区别只有一点：**试次顺序每人随机**（26 人共 24 种不同序列，本会话从 EEG marker 核实）。

修复的两个数据问题（与本分析无关，但必须修复才能运行）：

## 结果（机会水平 50%，n = 26）

| 分析 | 指导语前再留出 | EEG | fNIRS（均值+斜率） |
|---|---|---|---|
| **当前试次标签**（与 n-back 探针相同的问题） | 0 s | 52.1%（p = 0.014） | **50.3%（p = 0.46）** |
| 当前试次标签 | 2 s | **50.0%（p = 0.44）** | **51.9%（p = 0.13）** |
| 上一试次标签（残留有多强） | 0 / 2 s | 50.3% / 52.0% | 53.7%（p = 0.07）/ 54.1%（p = 0.012） |
| 固定上一试次标签后的当前标签（平衡准确率） | 0 / 2 s | 51.0% / 48.5% | 54.2%（p = 0.003）/ 52.7%（p = 0.028） |

**不用任何脑信号、只靠随机规则能达到的上限：**
- "当前 = 上一个的反面"：62.2%（所有人的切换概率都是 0.62）；
- "每个 run 正好 10 个 WG + 10 个基线，猜剩余较多的那一类"：**66.8%**；固定上一试次后的平衡准确率为 60.3%。

## 解读

1. **顺序每人随机时，开始前探针基本回到机会水平**：fNIRS 当前标签为 50.3% / 51.9%（不显著）；同样的被试和处理方式，在共用顺序的 n-back 上是 +6 ~ +7 点（p ≈ 0.003）。这就是论文需要的阴性对照。
2. EEG 在 0 s 间隔时有 +2.1 点（p = 0.014），2 s 间隔时消失，可能是指导语前后的边界效应，如实报告。
3. **随机化约束本身就是一个共享通道**：每个 run 内 10/10 平衡、切换概率 0.62 对所有人都一样，只靠规则就能猜对 62–67%。fNIRS 在固定上一试次后还剩 +2.7 ~ +4.2 点，量级远低于规则上限，最可能的来源就是这个约束（剩余计数）加上上一试次的血流残留。
   这说明"每人随机"还不够，**随机化规则也不能对所有人相同**（或者至少要报告规则本身能提供的上限）。这一点可以作为论文的附加发现。
